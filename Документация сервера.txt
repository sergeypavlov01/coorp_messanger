    ПРОТОКОЛ УЧЕБНОГО WEBSOCKET-СЕРВЕРА
    ====================================

    Адрес по умолчанию: ws://127.0.0.1:8080/chat
    Обмен выполняется JSON-объектами в текстовых WebSocket-фреймах.

    Рекомендуемая последовательность:
    1. Открыть WebSocket-соединение.
    2. Отправить setMyName.
    3. После success запросить whoAmI.
    4. После iAm запросить getConnectedUsers и открыть экран чата.
    5. Продолжать принимать сообщения независимо от исходящих запросов.

    ЗАПРОСЫ КЛИЕНТА
    ---------------

    Установить имя:
    {
      "reqType": "setMyName",
      "newName": "Николай"
    }

    Узнать текущего пользователя:
    {
      "reqType": "whoAmI"
    }

    Получить подключённых пользователей:
    {
      "reqType": "getConnectedUsers"
    }

    Отправить сообщение всем:
    {
      "reqType": "reqSendAll",
      "message": "Всем привет!"
    }

    Отправить сообщение одному пользователю:
    {
      "reqType": "reqSendMessage",
      "toUser": {
        "id": 1711330732,
        "name": "Николай"
      },
      "message": "Привет!"
    }

    ОТВЕТЫ СЕРВЕРА
    --------------

    Успешное выполнение:
    {
      "respType": "success",
      "successText": "Описание результата"
    }

    Ошибка:
    {
      "respType": "error",
      "errorText": "Описание ошибки"
    }

    Текущий пользователь:
    {
      "respType": "iAm",
      "user": {"id": 593372104, "name": "Томми"}
    }

    Список пользователей:
    {
      "respType": "connectedUsers",
      "listOfUsers": [
        {"id": 1767907798, "name": ""},
        {"id": 1890777498, "name": "Сергей"}
      ]
    }

    Входящее сообщение:
    {
      "respType": "sendMessage",
      "fromUser": {"id": 227556556, "name": "Николай"},
      "message": "Привет, Сергей!"
    }

    Поле respType определяет вид ответа. Клиент не должен полагаться на порядок
    сообщений, кроме непосредственного сценария авторизации.
